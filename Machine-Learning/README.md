Machine Learning – Customer Churn Prediction

Project Overview

This project focuses on predicting customer churn using machine learning techniques and the Telco Customer Churn dataset.

Tools & Skills

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Data Cleaning
- Feature Encoding
- Model Training
- Hyperparameter Tuning
- Model Evaluation

Key Analysis

- Cleaned and prepared customer churn data
- Handled missing values and converted data types
- Encoded categorical features for machine learning
- Trained multiple classification models
- Compared model performance using evaluation metrics
- Performed hyperparameter tuning using GridSearchCV
- Selected XGBoost as the best-performing model
- Analyzed feature importance
