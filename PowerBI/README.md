Power BI – DMart Sales Analysis

Project Overview

This project focuses on analyzing DMart sales data and creating an interactive Power BI dashboard to understand sales and business performance.

Tools & Skills

- Power BI
- Power Query
- Data Cleaning
- Data Modeling
- DAX
- Data Visualization
- Interactive Dashboard Development

Key Analysis

- Analyzed total sales and profit
- Compared sales performance across categories and products
- Analyzed profit margin and business performance
- Identified sales trends and growth
- Created KPI cards and interactive visualizations
