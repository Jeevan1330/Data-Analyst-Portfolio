SQL – Online Movie Ticket Booking Analysis

Project Overview

This project analyzes online movie ticket booking data to understand customer booking behavior, movie popularity, theatre performance, and revenue trends.

Tools & Skills

- MySQL
- SQL Queries
- JOIN
- GROUP BY
- HAVING
- Subqueries
- CTEs
- Aggregate Functions
- Date Functions
- Window Functions

Key Analysis

- Analyzed total booking and revenue trends
- Identified the most popular movies
- Analyzed city-wise booking performance
- Compared theatre performance
- Studied show timing and booking patterns
- Identified customer booking behavior
